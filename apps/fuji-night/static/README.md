# Night Photography Camera Guide

A budget-tiered camera + lens recommendation guide for night photography. Fuji-focused (for the film aesthetic), with Sony a6000 alternative, rental options, and used-market deals.

**Live site:** https://bubakazouba.github.io/fuji-night-photography-guide/

## What's inside

- 9 camera + lens setups, ranked from cheapest to most capable
- Sony a6000 budget alternative
- Try-before-you-buy rental options (US-focused)
- Used market deals worth hunting
- Fuji film simulation primer
- Starting camera settings for night shooting
- Smart accessories under $200
- A "my pick" recommendation if you want to skip the choice

Single static page, no build step, hosted on GitHub Pages.
