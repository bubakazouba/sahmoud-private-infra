2 · What is already right (externally validated — keep)

  • KEEPThree-tier memory with human-readable, git-diffable files — the exact converged 2026 pattern (OpenClaw ships literally MEMORY.md + logs + vector store). agentailor.com · danielmiessler.com/blog/personal-ai-infrastructure
  • KEEPProvenance on extracted facts (msg-id pointers, shipped 7/02) — the literature calls this an OPEN research problem; we already do it. arxiv 2606.04990
  • KEEPsqlite over a broker — correct at single-machine scale (100k+ ops/s WAL); Redis/NATS only pays off multi-machine. dev.to sqlite-queue
  • KEEPHard-assert driver pattern (whatsapp_send) = the literature "verify-before-act checkpoint" for side-effecting UI actions. digitalapplied.com · HalluClear arxiv
  • KEEPLong-poll over webhook for a home machine (no public endpoint needed; TG rejects concurrent getUpdates anyway — see P1). gramio.dev · hostman.com

3 · Real failure modes (every one happened HERE, mostly 7/01-02)

Session-id clobbering, 3 holes: cwd-only guard → reboot resumed a throwaway test session; env-marker inheritance → claude -p children stole the id twice more. Two holes patched; brain-spawned one-shots outside mem0_capture still inherit (→ P9).
Watchers die with the session, silently: the email-arc Monitor from an old session was gone; an OpenAI reply sat unread until Sahmoud noticed (→ P3). Matches the classic silent-gateway postmortem. hermes-agent.ai gateway troubleshooting
Process-alive ≠ loop-healthy: the brain check counts claude processes; a wedged brain looks identical to a healthy one (→ P2).
Wrong-textbox automation: WhatsApp search-typing landed in Preksha's composer → 2 stray sent messages + a stray draft; execCommand deletes silently no-op; tab indices reshuffle (2 misclicks); ad iframes match URL greps; a heavy SPA wedged its renderer for an hour (→ P5).
Log = IPC coupling: scrubbing 2 lines from the poller log flipped grep to binary mode and blinded the Monitor until restarted with -a (→ P8).
Attribution: relayed voice notes carry the sender ACCOUNT, not the speaker — Preksha's note recorded as his until corrected (→ P10).
Message-loss window: if the brain is down, messages get logged but nothing systematically REPLAYS unprocessed rows on wake (→ P1).
Shell landmines: PowerShell ate dollar signs in a reminder text; bash-vs-PS heredoc traps; missing git identity in subshells; ensure_poller 15s wrapper timeout reports failure on success.

Considered and deliberately NOT recommended (for now)

  • Gateway rewrite (OpenClaw-style single daemon owning all channels): the dominant industry pattern, but a full rewrite; P1+P2+P3 buy ~80% of its reliability for ~5% of the cost. Revisit if multi-platform inbound becomes real.
  • Memory framework switch (Zep/Letta): the mem0-vs-Zep benchmark fight is vendor marketing (49% vs 63.8% independent; 92-94% self-claimed; rebuttals both directions). Our Claude-extraction + provenance already addresses the actual quality complaint. Judge by our own recall misses, not their charts. particula.tech · blog.getzep.com · mem0.ai/blog
  • Webhook migration: needs a public HTTPS endpoint from a home machine; long-poll + P1 dedup is the right shape here.
