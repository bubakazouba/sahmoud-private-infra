Applies to: ALL charts (re-aggregated from per-day data). Extended analyses (heatmap, reactions, latency, language, photos, pair-coactivity) cover the full data window.
What's not counted: Phone/video calls, "Group video call" tiles, reactions, and system messages (joins/renames) are excluded from message counts. How links are detected: Combined regex on full message text + href extraction from all anchor tags + l.messenger.com redirect decoding (real URL extracted from the u= param). Facebook profile @mention links excluded. Domain classification via URL parser, not substring match. Message type classifier: FB reels, FB video shares, YT links, and IG reel links are classified as LINK subtypes -- not "video". Only real camera-roll MP4 uploads (m["videos"] in DYI JSON) stay as type=video. Link subtypes: link_fb_reel, link_fb (all other Facebook shares), link_yt (YouTube), link_ig (Instagram), link_other. Source: FB Data Download (DYI JSON archive) -- ground truth, no DOM scraping. Mojibake fixed via latin1->utf-8. Unsent/deleted messages excluded.
