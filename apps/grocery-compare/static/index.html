🛒 LA vs Austin Grocery Prices

Apples-to-apples basket comparison · custom dataset (no existing source) · pulled
MVP status: data acquisition is partial because most grocery store sites are bot-protected (Incapsula, Cloudflare) or hide prices behind JS that requires real-browser execution. screenshot-based comparison is the honest compromise — visual eyeball check of search-result pages from each store. fuller automated price extraction would take additional work to bypass those defenses.
Method: For each item, search the SAME query string ("large eggs dozen grade a", etc.) at each store. Take a screenshot of the first page of results. Manually note the comparable price next to it where visible. Stores: Ralphs (LA Pasadena), HEB (Austin), Whole Foods (both — via amazon.com ZIP switch), Trader Joe's (national uniform price as baseline).
